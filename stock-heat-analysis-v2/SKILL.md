# Stock Heat Analysis v2 - 股票热度分析 Skill

## 📌 触发词

当用户提到以下内容时，使用此 skill：
- 股票热度、热度分析、散户关注度
- 热股分析、热度因子、关注度评分
- 预测涨跌、明日预测、近期预测追踪
- 批量预测、多股票分析
- 回溯测试、准确率验证

---

## 🎯 功能概述

基于**7因子热度模型**的 A股量化分析工具，通过公开市场数据构建热度因子体系，量化评估股票受散户关注程度，并预测短期涨跌方向。

### 核心特性

✅ **7因子热度模型** - 成交额、换手率、量比、资金流、振幅、成交CV、散户行为  
✅ **逆向逻辑** - 高热度=散户过热=看空，低热度=散户冷淡=看多  
✅ **趋势识别优化** - 层面一优化，强趋势下覆盖逆向预测  
✅ **批量预测** - 支持1只或多只股票同时分析  
✅ **回溯测试** - 历史预测准确率验证  
✅ **5日追踪** - 自动对比近5日预测与实际涨跌

## 🚀 使用方法

### 1. 单只股票预测

**完整流程** (获取数据 → 预测):
```bash
cd /path/to/stock-heat-analysis-v2
python3 scripts/run.py --code 600000
```

**仅预测** (已有K线数据):
```bash
python3 scripts/predict.py --code 600000 --data-dir ./data
```

### 2. 批量股票预测 (新增)

**逗号分隔**:
```bash
python3 scripts/batch_predict.py --codes 600000,000001,300750
```

**空格分隔**:
```bash
python3 scripts/batch_predict.py 600000 000001 300750
```

**单个股票** (兼容):
```bash
python3 scripts/batch_predict.py --codes 600000
```

**指定目录**:
```bash
python3 scripts/batch_predict.py --codes 600000,000001 \
  --data-dir /path/to/data --output-dir /path/to/output
```

**输出**:
- 每只股票的标准预测报告
- 汇总对比表（代码、名称、方向、概率、置信度、热度、趋势）
- 批量汇总JSON (`batch_summary_Nstocks.json`)

### 3. 回溯测试

**5日回溯**:
```bash
python3 scripts/backtest_5day.py --code 600000 --days 5
```

**10日回溯**:
```bash

```

**输出**:
- 逐日预测vs实际涨跌对比表
- 准确率统计
- 回溯报告JSON

## 📊 预测逻辑详解

### 7热度因子

| 因子 | 名称 | 说明 | 逆向逻辑 |
|------|------|------|----------|
| F1 | 成交额 | 当日/20日中位数 | 成交暴增→散户追涨→偏空 |
| F2 | 换手率 | 原始值 | 换手率超高→过热→偏空 |
| F3 | 量比 | 今日量/5日均量 | 量比>2→热度↑→偏空 |
| F4 | 资金流 | 涨跌幅×振幅(取负) | 主力流出→偏空 |
| F5 | 振幅 | (高-低)/收盘×100% | 波动大→情绪高→偏空 |
| F6 | 成交CV | 5日成交量变异系数 | 异常放量→散户涌入→偏空 |
| F7 | 散户行为 | 涨跌幅×换手率(取负) | 追涨特征明显→偏空 |

**综合热度得分** = Σ(因子Z值) / 7

### 预测规则

| 热度得分 | 预测方向 | 基础概率 |
|---------|---------|---------|
| > +1.5 | 下跌 | 75% |
| +0.8 ~ +1.5 | 下跌 | 65% |
| +0.3 ~ +0.8 | 震荡偏空 | 55% |
| -0.3 ~ +0.3 | 震荡 | 50% |
| -0.8 ~ -0.3 | 震荡偏多 | 55% |
| -1.5 ~ -0.8 | 上涨 | 65% |
| < -1.5 | 上涨 | 75% |

### 修正因子

1. **价格位置修正** - 区间低位+4%看多，高位-4%看空
2. **多空投票修正** - 每多1个多头信号+2%，空头-2%
3. **趋势覆盖** (层面一优化) - 强趋势下覆盖逆向预测

### 趋势识别 (层面一优化)

**判定方法**:
- 近10日平均涨跌幅 (60%权重) + 首尾斜率 (40%权重) = trend_score
- 趋势状态: bullish_strong / bullish_weak / neutral / bearish_weak / bearish_strong

**覆盖逻辑**:
- `bullish_strong` + 预测下跌 → 翻转为上涨
- `bearish_strong` + 预测上涨 → 翻转为下跌
- `bullish_weak` + 预测下跌 → 改为震荡
- `bearish_weak` + 预测上涨 → 改为震荡

## 🔍 回溯测试解读

### 准确率计算

- **有效预测** - 排除"未知"结果（目标日K线缺失）
- **判断标准**:
  - 预测"上涨" → 实际涨跌幅 > 0 → ✅
  - 预测"下跌" → 实际涨跌幅 < 0 → ✅
  - 预测"震荡" → |实际涨跌幅| ≤ 1.5% → ✅

### 优化效果评估

运行回溯测试可以评估模型在历史数据上的表现：

```bash
# 对某只股票进行10日回溯测试
python3 scripts/backtest_5day.py --code 600000 --days 10
```

**解读方法**:
- 准确率 > 50%：模型有效（随机基线50%）
- 准确率 < 50%：模型需要调整参数或因子权重
- 分析错误案例：查看哪些日期预测错误，分析原因

**优化方向**:
- ✅ 强趋势股（如连续上涨）准确率提升显著
- ⚠️ 震荡/弱趋势股可能被趋势识别误伤
- 🔧 可调整强趋势触发阈值（0.4 → 0.6）减少副作用
- 🔧 可调整因子权重（编辑 `predict.py` 第45行 `FACTOR_WEIGHTS`）

## 📝 注意事项

1. **数据来源** - 同花顺历史K线 + 新浪财经实时行情（无需API token）
2. **预测时效** - 建议在收盘后运行（15:00后），数据最完整
3. **热度高≠一定跌** - 模型给出概率性预测，非确定性结论
4. **趋势覆盖** - 强趋势下模型会放弃逆向逻辑，跟随趋势
5. **回溯限制** - 需有历史预测JSON文件才能追踪准确率

## 🚨 常见问题

### Q1: 批量预测会节省 token 吗？

**会**。原因：
- 减少重复加载 Python 环境
- 共享系统提示处理
- 减少对话轮次（3次独立 → 1次批量）

### Q2: 如何更新模型参数？

编辑 `predict.py`:
- 因子权重: `FACTOR_WEIGHTS` (第45行)
- 信号阈值: `SIGNAL_HIGH` / `SIGNAL_LOW` (第48-49行)
- 趋势阈值: `detect_trend()` 函数内 (第227-236行)

### Q3: 如何添加新的热度因子？

1. 在 `FACTOR_NAMES` 列表添加新因子名
2. 实现因子计算函数（参考 `_f1_amount_heat()` 等）
3. 在 `compute_all_factors()` 中调用
4. 调整 `FACTOR_WEIGHTS` 使总和为1

### Q4: 预测准确率不高怎么办？

- 运行回溯测试，定位问题股票
- 调整因子权重（某些因子可能噪音大）
- 启用/调整趋势识别参数
- 考虑增加层面二/三优化（行业热度、量价背离）
