# 股票热度分析 v2 (Stock Heat Analysis)

基于热度因子概念，利用**公开可获取的A股市场数据**，构建代理热度因子体系，实现对股票散户关注度的量化分析和预测。

> **v2 改进**：数据获取层全面替换为公开无认证接口（同花顺+新浪+东方财富fallback），固定化全流程脚本，AI 调用一条命令即可完成分析，token 消耗降低约 75%。

---

## 快速开始（AI 标准调用流程）

### 第一步：运行分析脚本（AI 请求用户确认后执行）

```bash
# 分析单只股票（推荐方式，一条命令完成全流程）
cd stock-heat-analysis-v2
python3 scripts/run.py --code 600000

# 批量分析
python3 scripts/run.py --code 600000,000001,300750

# 自定义天数（默认40个交易日）
python3 scripts/run.py --code 600000 --days 30

# 自定义输出目录
python3 scripts/run.py --code 600000 --output-dir /tmp/heat_out
```

### 第二步：AI 读取结果文件并解释

```bash
# 脚本运行完成后，读取这个文件即可
cat ./output/600000_predict_YYYYMMDD.json
```

结果文件包含：综合热度分数、7因子Z值、明日预测方向/概率/置信度、近5日追踪准确率。

## 核心原理

### 7个热度因子（公开数据代理）

| 原始因子（软件内部） | 公开代理指标 | 因子编号 |
|---------------------|------------|---------|
| 点击量 | 成交额相对20日中位数 | F1 |
| 新闻点击量 | 换手率 | F2 |
| 自选操作 | 相对5日均量（量比代理） | F3 |
| 加仓信号 | 振幅×涨跌幅（主力行为代理） | F4 |
| 搜索量 | 日内振幅 | F5 |
| 分享数 | 5日成交量变异系数 | F6 |
| 讨论量 | 换手率×涨跌幅（散户追涨代理） | F7 |

**核心逻辑（逆向）**：IC值为负 → 高热度=散户情绪过热=后续收益倾向为负。预测时使用逆向信号。

### 热度分数解读

| 热度分数 | 含义 | 预测倾向 |
|---------|------|---------|
| > +1.5 | 过热🔥🔥 | 下跌（75%） |
| +0.8 ~ +1.5 | 偏热⚠️ | 下跌（65%） |
| +0.3 ~ +0.8 | 中性偏热 | 震荡偏空（55%） |
| -0.3 ~ +0.3 | 中性✅ | 震荡（50%） |
| -0.8 ~ -0.3 | 中性偏冷 | 震荡偏多（55%） |
| -1.5 ~ -0.8 | 偏冷❄️ | 上涨（65%） |
| < -1.5 | 极冷❄️❄️ | 上涨（75%） |

## 注意事项与局限性

1. **准确率因股而异**：趋势明显的股票（强势股/弱势股）模型可能连续给出错误信号（如连续下跌趋势中持续给"偏多"信号）
2. **非交易时段**：实时行情返回最近收盘价，振幅等盘中指标为0
3. **F4/F7因子数据限制**：v2因公开K线无大/小单数据，F4和F7使用代理指标（涨跌幅×振幅/换手率），与原始逻辑有差异
4. **北交所股票**：市场推断可能不准确，建议手动确认
